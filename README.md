# Habit Flow

A modern habit tracking application built with **React**, **TypeScript**, **Firebase**, and **Tailwind CSS** to help users build consistency, track daily habits, and visualize their progress over time.

---

## 📖 Overview

Habit Flow is a personal productivity application designed to make habit building simple and engaging. Users can securely sign in with Google, manage their daily habits, monitor completion history, and analyze progress through an intuitive dashboard.

This project uses Firebase Authentication and Cloud Firestore for secure user management and cloud data synchronization.

---

## ✨ Features

- 🔐 Google Authentication
- ✅ Create, update, and delete habits
- 📅 Calendar-based habit tracking
- 📊 Progress statistics and analytics
- ☁️ Cloud synchronization with Firebase Firestore
- 📱 Responsive user interface
- ⚡ Fast and lightweight experience using Vite

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Dayanithi030208/habit-flow.git

cd habit-flow
```

### Install dependencies

```bash
npm install
```

### Configure Firebase

Create your Firebase project and enable:

- Authentication (Google Provider)
- Cloud Firestore

Then configure your Firebase credentials.

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
